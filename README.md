# on-degenerate-geometric-rank
Code relating to "On degenerate geometric rank".

A brief showcase of how to use the code is available [here](howto.sage).

The scripts to check the individual computational assertions in the paper are:
* The octonion structure tensor: [here](octonions.sage)
* The invariant tensor in $S^2\mathbb C^3\otimes S^2\mathbb C^3\otimes S^2\mathbb C^3$: [here](E6.sage)
